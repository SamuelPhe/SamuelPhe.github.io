Saya mahasiswa Sistem dan Teknologi Informasi di Institut Teknologi & Bisnis Sabda Setia (ITBSS), sekaligus bekerja sebagai Accounting Staff di industri perhotelan.

Saya tertarik pada bagaimana teknologi bisa membantu pekerjaan sehari-hari. Di luar pekerjaan, saya mengerjakan proyek akademik dan personal untuk mengenal proses pengembangan software secara lebih nyata—mulai dari merancang alur, mengelola data, sampai mencoba membuat aplikasi berjalan.

Saya belum menganggap diri saya ahli. Sebagian besar pengalaman coding saya berkembang lewat tugas kuliah, dokumentasi, eksplorasi mandiri, dan bantuan AI. Karena itu, saya berusaha menampilkan apa yang benar-benar pernah saya kerjakan, sekaligus hal-hal yang masih perlu saya pelajari.
