# Samuel Phe — Portfolio v2

An alternate personal portfolio site, published separately from the original homepage.

- **Live path (after GitHub Pages finishes publishing):** https://samuelphe.github.io/v2/
- **Original portfolio:** https://samuelphe.github.io/
- **Source:** `v2/index.html`, `v2/styles.css`, and `v2/script.js`

## Design notes

This version uses an original editorial direction: warm paper surfaces, deep charcoal sections, a restrained burgundy and coral-red accent, typographic layouts, and CSS-drawn project illustrations. The references supplied for the redesign were used only as broad inspiration for presentation quality and interaction; their layouts, copy, and assets were not reproduced.

## Features

- Responsive navigation for desktop and mobile
- Project filters (All, Web, Desktop, Research)
- Keyboard command palette using `Ctrl/Cmd + K`, with arrow-key navigation and an empty-search state
- Local time display for West Kalimantan (Asia/Pontianak)
- Scroll reveal effects with reduced-motion support
- No frontend framework or build step required

## Editing

Update the content in `index.html`, presentation in `styles.css`, and interactions in `script.js`. All illustrations are drawn with CSS and HTML; no third-party project screenshots are embedded.

The original root-level `index.html` and `portofolio.html` remain the V1 experience and include links to switch to V2. The V2 header links back to the original homepage.


## Profile information

The profile content includes the supplied LinkedIn details for education, employment, languages, and IMPHNEN membership. The contact phone number is intentionally not published on the portfolio; the email and professional profile links remain available. Blender is listed as a tool the owner has used, without claiming professional mastery.
